**Font Guideline**

light font color
font color = #716578
font = Zekton Free

background color = #000000

glow color = #BFB8FE

font = Megalomania
font size = 72

Create VS Text
- In GIMP 2.00: create selection:
  Layer > Text to Selection > Text to Selection
- In GIMP 2.10: create selection:
  Layer > Selection from Alpha
- Create new layer (or reuse existing)
- Rename layer to _glow
- Select layer
- Select > Grow = 1 (was 2)
- Select > Feather = 3 (was 6)
- Fill with bg/fg color
- Stack layer below font
